# Leadership portraits

Profiles fall back to a generated initials avatar when a leader has no photo.

To use a real portrait:

1. Drop a square image here, e.g. `web/img/leaders/irfan-razack.jpg`.
2. Set that leader's `photo` field in `server/data/developers.json`:

   ```json
   { "name": "Irfan Razack", "role": "Chairman & Managing Director",
     "photo": "/img/leaders/irfan-razack.jpg" }
   ```

Only use images you have the rights to publish. Press-kit and corporate
photographs are usually licensed for editorial use only, not for
redistribution on a third-party site, so check before adding one.
